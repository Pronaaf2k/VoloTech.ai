# Satoshi

Satoshi by Deni Anggara, distributed by Indian Type Foundry through Fontshare.

- Source: https://www.fontshare.com/fonts/satoshi
- Downloaded directly from https://api.fontshare.com/v2/fonts/download/satoshi on 2026-09-18.
- Unmodified `Satoshi-Variable.woff2`, normal style, supported weight range 300–900.
- License: accompanying `FFL.txt`. Self-hosted for this VoloTech website.
- IBM Plex Mono remains self-hosted through the existing `@fontsource/ibm-plex-mono` package at weight 400.

The FFL allows website self-hosting but restricts redistribution as a font resource. External collaborators should obtain their own font copy directly from Fontshare.
